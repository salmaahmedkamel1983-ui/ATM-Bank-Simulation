# 🏧 ATM Banking System Simulation

A simple command-line Python project that simulates an Automated Teller Machine (ATM) banking system. It allows users to manage their bank accounts securely with multi-language support (Arabic & English).

---

## 🚀 Features (المميزات)
* **Security Authentication:** Card number and password verification with a maximum of 3 attempts before locking the card.
* **Multi-language Support:** Fully functional interface in both **English** and **Arabic (اللغة العربية)**.
* **Account Operations:**
  * Balance Inquiry (استعلام عن الرصيد)
  * Cash Withdrawal with predefined amounts (100, 500, 1000) or custom manual amount with strict limit checks (سحب نقدي)
  * Cash Deposit (إيداع نقدي)
* **Error Handling:** Validates negative inputs, insufficient funds, and maximum withdrawal limits.

---

## 🛠️ Tech Stack (التقنيات المستخدمة)
* **Language:** Python 3
* **Concepts:** Loops (`for`, `while`), Conditional Statements (`if-elif-else`), Input/Output handling.
